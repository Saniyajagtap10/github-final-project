# Paradise Nursery

## Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop application where users can browse houseplants, view plant details, add plants to a shopping cart, and manage cart items.

## Features

* Browse houseplants by category
* View plant images, names, descriptions, and prices
* Add plants to the shopping cart
* Increase or decrease quantity
* Remove plants from the cart
* View total cart amount
* Continue shopping
* Checkout option with a "Coming Soon" message

## Technologies Used

* React
* Redux
* JavaScript
* CSS
* Vite
